# 홈 카드 표시 규칙

> 기준: [test_codex `02_HOME_CARD_DISPLAY_RULES.md`](https://github.com/livbee-project/test_codex/blob/main/docs/02_HOME_CARD_DISPLAY_RULES.md)  
> 구현: `src/presentation/pages/home/`, `src/presentation/components/home/`

## 목적

메인페이지는 쇼호스트·모델·브랜드 공고를 빠르게 판단하고 상세·매칭 액션으로 이어지게 한다.  
조회수, 시청자 수, 좋아요, 영상 길이 등 플랫폼 지표는 **메인 카드에서 사용하지 않는다.**

## 헤더 (`ServiceHeader`)

- 좌측: LIVBEE 로고
- 중앙: `홈` · `이벤트` · `뉴스` · `숏클립` · `커뮤니티` (데스크톱 1024px 이상)
- 우측: 검색 · 알림 · 로그인/마이페이지
- 콘텐츠 최대 폭: `1280px` (`theme.layout.contentWidth`)
- **모바일·태블릿(1023px 이하)**: 중앙 메뉴 숨김, 로고·우측 액션 우선

## 공통 카드

- radius `16px`, `listCardSurface` (1px 연한 테두리 + 옅은 그림자)
- 이미지 상단 · 텍스트 하단
- 텍스트 영역 padding 최소 `12px` (모바일), PC `16~18px` 권장
- 제목·설명 각 **최대 2줄** 말줄임
- **이미지 위 핵심 텍스트 겹침 금지** (출연료·카테고리 배지 등)
- 섹션 내 카드 높이 균일 유지
- 모바일 가로 스크롤, PC 카드 개수 증가

## 타이포

- 추천 모델 이름 = 카드 제목 기준: `15px`, `weight-title`, 1줄 말줄임
- HOT CLIP·라이비 뉴스 제목도 **동일 크기·굵기** (PC에서 임의 확대 금지)

## 태그

- 최대 5개, **한 줄** 가로 스크롤, 줄바꿈으로 카드 높이 증가 금지

## 브랜드 PICK (`CampaignCard`)

| 항목 | 규칙 |
|------|------|
| 이미지 비율 | `4:3` |
| 노출 순서 | 이미지 → 제목 → 한 줄 소개 → **출연료(강조)** → 브랜드명 → 촬영일 |
| 링크 | `/campaigns/:campaignId` |

## 지금 뜨는 라이브 (`LiveCard`)

| 항목 | 규칙 |
|------|------|
| 이미지 비율 | `4:5` |
| 노출 | 이미지, 제목, 한 줄 소개, 방송일/촬영일 |
| 금지 | LIVE 뱃지, 시청자·조회수, 상품 썸네일 행 |

## 추천 쇼호스트 (`ProfileCard` type=host)

| 항목 | 규칙 |
|------|------|
| 이미지 | `1:1` **원형**, 카드 상단 중앙 |
| 노출 | 프로필, 이름, 한 줄 소개, 태그, **제안하기** · **메시지 보내기** |
| 금지 | 평점·팔로워·SNS 수치 |

## 추천 모델 (`ProfileCard` type=model)

| 항목 | 규칙 |
|------|------|
| 이미지 | `4:5` 카드 상단 풀 이미지 |
| 노출 | 프로필, 이름, 한 줄 소개, 태그, CTA 2종 |
| 이름 스타일 | 홈 카드 제목 기준(15px) |

## HOT CLIP (`ClipCard`)

| 항목 | 규칙 |
|------|------|
| 이미지 비율 | `9:16` |
| 노출 | 썸네일, 제목, 한 줄 소개 |
| 금지 | 재생 시간, 조회수, 좋아요 |

## 라이비 뉴스 (`NewsCard`)

| 항목 | 규칙 |
|------|------|
| 이미지 비율 | `16:9` |
| 노출 | 이미지, **카테고리(텍스트 영역)**, 제목, 작성일 |
| 금지 | 이미지 위 카테고리 배지 겹침 |

## 반응형

| 구간 | 기준 |
|------|------|
| Mobile | 375px, 가로 스크롤, 브랜드 PICK 2~2.5장 노출 |
| Tablet | 768~1023px, 섹션당 3~4장 |
| Desktop | 1024px+, max 1280px, 카드 개수 확대 |

## 금지 사항 요약

- 텍스트가 카드 테두리에 붙는 구성
- 태그 줄바꿈으로 카드 높이 증가
- 조회수·시청자·좋아요·영상 길이
- 이미지 위 핵심 텍스트 오버레이
- HOT CLIP만 테두리/그림자 예외
